# Análise e Desenvolvimento de Sistemas - Aula 2

Este repositório foi criado para armazenar e organizar os códigos práticos desenvolvidos durante as aulas de programação. O objetivo principal é fixar os conceitos teóricos de lógica e acompanhar a minha evolução prática na linguagem.

## 🚀 Sobre o Projeto

Durante esta unidade de estudos, o foco foi compreender a sintaxe inicial e aplicar conceitos essenciais de desenvolvimento de software.

Os principais tópicos explorados foram:

- Configuração do ambiente de desenvolvimento moderno
- Criação de scripts estruturados
- Manipulação de variáveis e exibição de dados

## 🛠️ Tecnologias e Ferramentas

- Python - Linguagem principal utilizada para o desenvolvimento dos scripts
- Visual Studio Code - Ambiente de desenvolvimento integrado (IDE) principal
- Git & GitHub - Ferramentas utilizadas para o controle de versão e documentação do portfólio

## 💻 Como Executar o Projeto

Para rodar os arquivos deste repositório na sua máquina local, certifique-se de ter o Python instalado e execute o comando abaixo no terminal:

'''bash
python nome_do_arquivo.py
'''
